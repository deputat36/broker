## Проверки

- Новый `scripts/test-browser-smoke.cjs`: 33 сценария, ширины 360/390/430/768/1440; дополнительно резерв при выключенном JavaScript. Все ответы Web3Forms имитируются; письма тест не отправляет.
- Проверяются меню и Escape, контраст активной навигации, номер в одну строку, горизонтальная прокрутка, изображения, расчёт и перенос параметров, обязательные поля и согласие, сброс предпросмотра, успех/ошибка/таймаут, повторное нажатие и минимальное локальное хранение.
- Локальные `post-build-check.sh`, аудит ссылок/Schema.org/sitemap, синтаксис JS/Python и source-аудиты пройдены на предварительном HTML-просмотре. Он не заменяет каноническую Jekyll-сборку GitHub Actions.
- Перед слиянием обязательны полный зелёный CI и проверка его Jekyll-артефакта; после слияния — deploy и production-smoke. Актуальное состояние этих проверок видно в PR и Actions.
- Бюджеты ресурсов не повышались. Размеры файлов не объявляются измерениями Core Web Vitals.

Воспроизведение браузерной проверки: установить Playwright в окружение проверок, подготовить Jekyll `_site`, затем выполнить `BROKER_SITE_DIR=_site node scripts/test-browser-smoke.cjs`. Для существующего окружения с отдельным Chromium поддерживается `CHROMIUM_PATH`. Результаты и скриншоты по умолчанию записываются в `/tmp/broker-browser-smoke`.
